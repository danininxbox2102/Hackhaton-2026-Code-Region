# СТАРТЕР — интеллектуальный агрегатор вакансий

> **Кроссплатформенный клиент:** `Frontend/` (Vue), `Desktop/` (Electron) и `Mobile/` (Capacitor) используют одну веб-кодовую базу. Сборка нативных приложений — в стадии подготовки. [Инструкция](docs/cross-platform.md).

**СТАРТЕР** — проект для хакатона «Код региона — 2026», который помогает людям находить работу и осознанно выбирать профессию. Сервис объединяет вакансии из разных источников, объясняет сложные требования понятным языком и планирует персональные рекомендации на основе рассказа пользователя о себе.

> **Статус: разработка MVP.** В репозитории уже есть каркас API и клиента; импорт вакансий, ИИ-функции и полноценная интеграция пока в разработке.

## Основные возможности

- **Агрегация вакансий** — импорт из открытых источников (первый — «Работа России»), нормализация и исключение дублей.
- **Каталог** — поиск, фильтрация по региону, зарплате, формату работы, опыту и графику, карточка вакансии.
- **ИИ-упрощение** — превращение сложных описаний вакансий в понятные обязанности, требования и условия.
- **Персональный подбор** — пользователь рассказывает о себе свободным текстом и получает подходящие направления и вакансии с объяснением выбора.
- **Личный кабинет** — регистрация, профиль, избранное.
- **Отклик** — переход к исходному объявлению работодателя.

Ключевая идея — **не просто найти вакансию, но и понять, какая работа тебе подходит и почему**.

## Технологический стек

| Часть системы | Технологии |
| --- | --- |
| Backend | **Node.js 22+**, **Express 5**, **TypeScript** |
| REST API | OpenAPI 3 |
| База данных | **MySQL 8.4**, `mysql2/promise` |
| Авторизация | JWT (`jose`), Argon2id |
| Валидация | Zod |
| Защита и логирование | Helmet, CORS, Pino |
| Локальная инфраструктура | Docker, Docker Compose |
| Клиент | **.NET 10 / .NET MAUI**, C#, XAML; Blazor Hybrid планируется |
| ИИ (планируется) | OpenAI-совместимый API |
| Независимое QA | Python, pytest, httpx |
| Командная разработка | Git, отдельные ветки и Pull Requests |

**Примечание:** текущий `AppNative/` — шаблон .NET MAUI на XAML, а не готовый Blazor Hybrid. `Backend-Server/` — ранний прототип на .NET; основной backend перенесён на Node.js + Express.

Каноническая бизнес-схема MySQL ведётся отдельно: [hackaton-sql-scheme](https://github.com/manhattanattack/hackaton-sql-scheme).

## Быстрый старт backend

Потребуются **Node.js 22+**, npm, Docker Compose и Git.

```bash
git clone https://github.com/TerComPy/Hackhaton-2026-Code-Region.git
cd Hackhaton-2026-Code-Region/Node-Back
cp .env.example .env
# В .env замените JWT_SECRET и проверьте параметры MySQL.
docker compose up -d mysql
npm ci
npm run dev
```

API по умолчанию: `http://localhost:3000`.

Проверка:

```bash
curl http://localhost:3000/api/health
curl http://localhost:3000/api/ready
npm run typecheck
npm run build
```

**Важно:** `/api/ready` проверяет соединение с MySQL, но не готовность таблиц. Для регистрации и каталога необходимо применить каноническую SQL-схему и согласованный Node.js-адаптер авторизации. Подробности: [Node-Back/README.md](Node-Back/README.md) и [UPSTREAM_ALIGNMENT.md](Node-Back/docs/db/UPSTREAM_ALIGNMENT.md). Старые SQL-скрипты привязки к ASP.NET Identity для Node.js backend **не запускать**.

### Доступные маршруты API

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| GET | `/api/health` | Проверка процесса |
| GET | `/api/ready` | Проверка MySQL |
| POST | `/api/auth/register` | Регистрация |
| POST | `/api/auth/login` | Вход |
| GET | `/api/auth/me` | Текущий пользователь |
| GET, PATCH | `/api/profile` | Профиль |
| GET | `/api/vacancies` | Каталог вакансий |
| GET | `/api/vacancies/:id` | Карточка вакансии |
| GET | `/api/favorites` | Избранное |
| PUT, DELETE | `/api/favorites/:vacancyId` | Управление избранным |
| POST | `/api/vacancies/:id/outbound-click` | Регистрация перехода к источнику |

Защищённые маршруты принимают `Authorization: Bearer <token>`. Полная спецификация: [openapi.yaml](Node-Back/docs/api/openapi.yaml).

## Текущий прогресс

- **Подготовлено:** Express boilerplate, базовые маршруты API, SQL-документация, соглашение об интеграции модулей.
- **Частично проверено:** TypeScript typecheck/build, отдельные smoke-проверки HTTP и JWT.
- **Требует проверки:** регистрация и транзакции на реальной MySQL, согласование связи `auth_users` с `user_profiles`.
- **В работе:** импортёр вакансий из «Работы России».
- **Запланировано:** ИИ-упрощение, персональный подбор, полноценные клиентские экраны и демонстрационный сценарий.

Наличие маршрута в исходном коде не означает завершённого интеграционного тестирования.

## Командная разработка и тестирование

Backend разрабатывают два агента: **Codex** отвечает за инфраструктуру, авторизацию, REST API и интеграцию, **Claude** — за импорт и нормализацию вакансий, а далее за ИИ-функции. Изменения передаются через Git Pull Requests. Схему БД согласовывает отдельный инженер. Независимый QA-инженер готовит внешние API-тесты на **Python (pytest + httpx)**.

Документация для разработчиков: [AGENTS.md](Node-Back/AGENTS.md), [контракт интеграции](Node-Back/docs/INTEGRATION.md), [QA handoff](Node-Back/docs/qa/HANDOFF.md).
